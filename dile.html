Начните за 2 минуты

Скопируйте код, вставьте свой API-ключ и начните использовать все модели.

import os
from openai import OpenAI

# Инициализация клиента
client = OpenAI(
    base_url="https://api.orbit.dev/v1",
    api_key=os.environ["ORBIT_API_KEY"]
)

# Отправка запроса
response = client.chat.completions.create(
    model="claude-sonnet-5-5",
    messages=[
        {"role": "user", "content": "Привет, Orbit!"}
    ],
    stream=True
)

# Получение ответа
for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")
import OpenAI from "openai";

// Инициализация клиента
const client = new OpenAI({
  baseURL: "https://api.orbit.dev/v1",
  apiKey: process.env.ORBIT_API_KEY,
});

// Отправка запроса
const stream = await client.chat.completions.create({
  model: "claude-sonnet-5-5",
  messages: [
    { role: "user", content: "Привет, Orbit!" }
  ],
  stream: true,
});

// Получение ответа
for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0].delta.content || "");
}
# Отправка запроса через cURL
curl https://api.orbit.dev/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ORBIT_API_KEY" \
  -d '{
    "model": "claude-sonnet-5-5",
    "messages": [
      {"role": "user", "content": "Привет, Orbit!"}
    ],
    "stream": true
  }'

Как получить API-ключ?
+
Купите пакет токенов и войдите в личный кабинет — ключ создаётся автоматически.
Токены сгорают?
+
Нет. Купленные токены хранятся на балансе бессрочно и списываются по мере использования.
Какие модели доступны?
+
GPT-4o, Claude Sonnet/Opus, Gemini, DeepSeek, Qwen, GLM, Kimi и другие — все через один ключ.
Есть ли стриминг?
+
Да, полноценный SSE-стриминг. Токены приходят по мере генерации.
